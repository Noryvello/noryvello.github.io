Retaining Wall Block Calculator

Enter your wall measurements and pick a block size, and this calculator works out how many courses of blocks the wall needs and the total block count, including a waste allowance. The working is shown so you can check every step.

Tall walls that hold back soil need professional design. This calculator only counts blocks. A tall wall, a wall holding back a slope, or a wall near a building should be designed by a professional. Always check local building practice before building.

How to use this calculator

Measure the wall length and height in metres. The height is the finished height of the wall above the ground. Pick the block size closest to the blocks you plan to buy. The picker shows the face size of each block, which is the part you see in the finished wall. Set the waste allowance, then press Calculate to see the courses and the total block count.

How the calculation works

The number of courses is the wall height divided by the block height, rounded up to a whole course, because a part course still needs a full row of blocks. The blocks per course are the wall length divided by the block length, rounded up the same way. The total is the courses multiplied by the blocks per course, plus the waste allowance. The steps show each part so you can check the figure.

How to use the result

Order the full block count shown, including the waste allowance, because cutting blocks for corners and ends uses up spares. Check the block size on the pack before ordering, because sizes vary by maker. Remember that this calculator counts blocks only. Drainage, a level base and the wall's stability all need planning too, and tall walls need professional design.

Questions people ask

What is a course?

A course is one horizontal row of blocks in a wall. The calculator divides the wall height by the block height to find how many rows the wall needs.

Why are the courses rounded up?

A wall cannot have part of a row, so the calculator rounds up to the next whole course. The top course may need cutting down if the height does not divide evenly.

Why is a waste allowance needed?

Cutting blocks for corners and ends, plus the odd broken block, uses up spares. The default allowance is 10 percent, and you can change it.

Do tall retaining walls need professional design?

Yes. This calculator only counts blocks. A tall wall, a wall holding back a slope, or a wall near a building should be designed by a professional, so get advice before building.

What else does a retaining wall need?

A level base, drainage behind the wall and proper backfill all matter, and this calculator does not cover them. Plan those parts separately, and follow local building practice.
