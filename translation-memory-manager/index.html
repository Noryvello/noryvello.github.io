What translation memory is

Translation memory is a simple idea that saves translators a great deal of time. Every time a translator finishes a sentence, the source sentence and its translation are stored together as a pair. The next time a similar sentence appears — in the same document, in an update, or in a completely different project — the memory shows the saved translation, so the translator does not start from zero. Over months and years, the memory grows into a personal library of approved translations.

The unit of a translation memory is the segment, which is usually one sentence. Translators work segment by segment, and the memory works the same way. When a new segment matches a saved one exactly, it is a 100 percent match, and the saved translation can be reused as it is. When it mostly matches, with a word or two changed, it is a fuzzy match, and the translator edits the changed words instead of translating the whole sentence again.

This matters most for texts that repeat themselves: software menus, product manuals, legal documents, and websites that are updated every month. A company that changes one paragraph of a fifty-page manual should not pay to translate the other forty-nine pages again, and with a translation memory, it does not have to.

How segments and matches work

Imagine you translated the sentence 'Welcome to our website' last year. This year the client changes it to 'Welcome to our new website'. A translation memory compares the new segment with the saved one, word by word, and reports a match percentage. One word out of five has changed, so the match is high — around 80 percent. The translator sees the old translation, changes one word, and moves on. The work takes seconds instead of minutes.

Try it with the match tester on this page. Type a saved segment and a new segment, and the tester shows the match percentage and what it means. A 100 percent match means the segments are identical. A match of 75 percent or more usually means the saved translation is worth reusing with small edits. A match below 50 percent usually means it is faster to translate the segment fresh.

Match percentages are a guide, not a judgement. A 90 percent match can still be wrong if the changed word is the important one — 'do not press the red button' and 'press the red button' differ by only one word, but they mean the opposite. A good translator always reads the match before accepting it. The memory suggests; the human decides.

How to build a glossary

A glossary is the other half of consistent translation. Where a translation memory stores whole sentences, a glossary stores single terms: product names, technical words, job titles, and any word that must always be translated the same way. A good glossary is short and strict: it lists the approved translation for each term and nothing else.

Start with the words that cause arguments. Every company has them: the product name that three translators spell three ways, the job title that becomes something different in every document, the technical term that one person translates and another leaves in English. Agree on one translation for each, write it in the glossary, and use it every time.

Add a short note to each entry when the reason is not obvious. 'Formal tone', 'website menu', 'do not translate', 'use the short form' — these notes save the next translator from guessing. Review the glossary every few months and remove terms you no longer use. A glossary with a thousand entries that nobody trusts is worse than a glossary with fifty entries that everyone uses.

Worked examples

A software menu. A small app has twenty menu items: Home, Settings, Help, Sign in, Sign out, and so on. The translator puts each one in the glossary with its approved translation. Six months later the app adds five new menu items and changes two old ones. The glossary gives the translator the approved wording for the unchanged items at once, and the translation memory gives high matches for the two changed ones. The update takes an hour instead of a day.

A product manual. A manual warns 'Do not open the case while the device is switched on' in twelve places. The first time, the translator translates it carefully and it goes into the memory. The next eleven times, the memory offers a 100 percent match, and the warning reads exactly the same in every place. Readers trust a manual that is consistent, and consistency is what the memory is for.

A website update. A company rewrites its homepage and changes three sentences out of forty. The translation memory matches the thirty-seven unchanged sentences at 100 percent, and the translator only works on the three new ones. The client pays for three sentences of work, not forty, and the translation stays consistent with the old version.

Free CAT tools to try next

When you are ready to move beyond this page, real CAT tools — computer-assisted translation tools — hold the memory, the glossary and the document together in one program. Several respected ones are free. OmegaT is a free, open-source translation memory tool that runs on most computers and handles common file formats. CafeTran Espresso offers a free version with a translation memory and glossary. MateCat is a free web-based tool that works in the browser. Wordfast offers a free version for smaller projects.

These tools do what this page cannot: they open your real documents, split them into segments, show matches as you type, and save everything in standard formats that other translators and agencies can use. This page is a place to learn the method; a CAT tool is where you do the real work. Try one of the free tools with a short document and see how the memory and the glossary feel in practice.

Whichever tool you choose, the method stays the same: translate segment by segment, reuse what the memory offers, check every match before you accept it, and keep your glossary short and strict. The tool changes; the craft does not.

Common mistakes

  • Accepting every match without reading it. A 95 percent match can still be wrong. The changed word may be the one that matters most. Read every match before you accept it.
  • A glossary nobody uses. A glossary that lives in a forgotten document helps no one. Keep it short, keep it where translators can find it, and update it when terms change.
  • Translating the same term two ways. If 'home page' becomes three different translations across a website, readers get confused and the site looks careless. One term, one translation, every time.
  • Storing bad translations. A memory is only as good as what goes into it. A wrong translation stored once gets reused a hundred times. Fix mistakes in the memory as soon as you find them.
  • Expecting the memory to translate. A translation memory stores past work; it does not create new translations. New sentences still need a human translator, and always will.

Questions people ask

What is translation memory?

Translation memory is a database of past translations, stored as pairs of source sentences and their translations. When a similar sentence appears again, the memory shows the saved translation so the translator can reuse it instead of starting over.

Do I need special software?

For real translation work, yes: a CAT tool holds the memory, the glossary and the document together. This page teaches the method and gives you a glossary manager to practise with, and it links to free CAT tools to try next.

What is a glossary?

A glossary is a list of approved translations for single terms: product names, technical words and job titles that must always be translated the same way. It keeps wording consistent across documents and translators.

How does a match percentage work?

The tool compares the new sentence with saved sentences word by word. A 100 percent match means the sentences are identical; a lower percentage means some words differ. High matches are worth reusing with edits; low matches are usually faster to translate fresh.

Can a beginner use translation memory?

Yes. The ideas are simple: store translations, reuse them, and keep a short glossary. Start with the glossary manager on this page, then try a free CAT tool with a short document to see the method in practice.

What is the difference between memory and machine translation?

Translation memory stores and reuses a human translator's past work. Machine translation creates new translations automatically with software. Many translators use both: the machine drafts, the memory keeps wording consistent, and the human checks everything.
