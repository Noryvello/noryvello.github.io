Cricket Run Rate Calculator

Short answer: current run rate is runs divided by overs bowled; required run rate is runs still needed divided by overs left. Type the match numbers below — overs use cricket notation, so 10.3 means 10 overs and 3 balls.

Overs are not decimals. In cricket notation 10.3 means 10 overs and 3 balls (63 balls), not 10.3 overs. The calculator converts for you — just type overs the way the scorecard shows them.

How the overs conversion works

Cricket overs count balls, not decimals. The number after the point is a ball count from 0 to 5: 10.3 overs is 10 overs and 3 balls, which is 63 balls, or 10.5 overs for division. The calculator converts every overs entry to balls first, then divides.

Worked examples

  1. 120 runs in 15 overs: 120 ÷ 15 = 8.00 runs per over.
  2. Target 180, 120 scored, 5 overs left: 60 runs needed ÷ 5 overs = 12.00 required.
  3. 87 runs in 10.3 overs: 10.3 is 63 balls = 10.5 overs, so 87 ÷ 10.5 = 8.29 current run rate.

What this calculator does not do

It does not apply Duckworth-Lewis-Stern adjustments for rain-shortened matches, and it does not calculate net run rate, which needs both teams' full runs and overs across a tournament.

Questions people ask

What is run rate in cricket?

Run rate is the average number of runs scored per over. Divide the runs scored by the overs bowled, converting balls correctly: 10.3 overs is 63 balls, which is 10.5 overs for the division.

How do I enter overs with balls?

Type overs the way the scorecard shows them, as overs.balls — for example 10.3 for 10 overs and 3 balls. The last digit must be 0 to 5, because six balls make an over.

What is the difference between current run rate and required run rate?

Current run rate is based on runs already scored divided by overs bowled. Required run rate is the runs still needed divided by the overs remaining — the pace the batting side must keep to reach the target.

Can this calculator be used for all formats of cricket?

Yes. The run rate arithmetic is the same in Tests, one-day matches and T20s, as long as the inputs are entered correctly. It does not apply Duckworth-Lewis-Stern adjustments for rain-shortened matches.
