File Transfer Time Calculator

Enter the size of a file and your connection speed, and this calculator tells you how long the transfer takes. It converts the file size to megabits, divides by your speed in Mbps, and shows the time in hours, minutes and seconds, with the working shown.

This calculator uses 1 GB = 1024 MB. Enter your download speed for downloads, or your upload speed for uploads.

This is an estimate based on the speed you enter. Real speeds vary with network load, the server, Wi-Fi quality and other traffic on the connection, so actual transfers are usually slower than the headline speed — expect the real time to be longer than the estimate.

How the maths works

The calculator works in three steps:

  1. Convert the file size to megabits. A size in MB is multiplied by 8, because 1 byte is 8 bits. A size in GB is multiplied by 1024 first to get MB, then by 8. This calculator uses 1 GB = 1024 MB.
  2. Divide by the speed. Time in seconds = megabits ÷ speed in Mbps.
  3. Turn seconds into a readable time. Seconds are rounded to the nearest whole second, then shown as hours, minutes and seconds.

time (seconds) = file size in megabits ÷ speed in Mbps

Megabytes vs megabits

File sizes and connection speeds use different units, and mixing them up is the most common mistake when guessing transfer times:

  • MB means megabytes. This is how file sizes are usually shown — a video, a game or a backup measured in MB or GB.
  • Mb means megabits. This is how connection speeds are usually shown — Mbps means megabits per second.
  • 1 byte = 8 bits. So 1 MB equals 8 Mb. A 500 MB file is 500 × 8 = 4,000 Mb of data, and at 50 Mbps that takes 4,000 ÷ 50 = 80 seconds.
  • The capital B matters. MB is megabytes, Mb is megabits. A file of 500 MB is eight times as much data as 500 Mb.

Worked examples

Example 1 — 500 MB at 50 Mbps. 500 MB = 500 × 8 = 4,000 megabits. 4,000 ÷ 50 = 80 seconds = 1 minute 20 seconds.

Example 2 — 2 GB at 100 Mbps. 2 GB = 2 × 1024 × 8 = 16,384 megabits. 16,384 ÷ 100 = 163.84 seconds, rounded to 164 seconds = 2 minutes 44 seconds.

Example 3 — 1 GB at 25 Mbps. 1 GB = 1 × 1024 × 8 = 8,192 megabits. 8,192 ÷ 25 = 327.68 seconds, rounded to 328 seconds = 5 minutes 28 seconds.

Why real transfers take longer

The calculator assumes your connection runs at full speed for the whole transfer. In practice it rarely does. The server you are downloading from may be busy, your Wi-Fi may be weak, other devices may be using the same connection, and the transfer itself has overhead — the data is wrapped in packets with extra information, so some of the speed is used by that rather than by your file. A useful rule of thumb: if the estimate says 2 minutes, allow a little more in real life.

Questions people ask

Why is the time worked out in megabits?

Because connection speeds are measured in megabits per second (Mbps). The file size has to be in the same unit before it can be divided by the speed, so the calculator first converts megabytes or gigabytes into megabits.

What is the difference between MB and Mb?

MB means megabytes and Mb means megabits. One byte is 8 bits, so 1 MB equals 8 Mb. File sizes are usually shown in MB, while connection speeds are shown in Mbps, which is why a 500 MB file is 4,000 Mb of data to move.

Why is my real download slower than this?

The headline speed of a connection is a maximum, not a promise. Network load, the server you are downloading from, Wi-Fi quality, other devices using the same connection and the overhead of the transfer itself all slow the real speed down, so real transfers usually take longer than the estimate.

Does it work for uploads too?

Yes. The maths is the same either way. Enter your upload speed instead of your download speed, and the calculator gives the upload time. Upload speeds are often lower than download speeds, so uploads of the same file usually take longer.
