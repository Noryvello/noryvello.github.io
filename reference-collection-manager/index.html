Reference Collection Manager

A reference collection manager keeps all your references in one place — books, articles and links, each with a note saying why it matters — and finds any source in seconds. This page gives you a working manager in your browser, plus a guide to building a collection you can trust. Everything you save stays on your device only, and nothing is uploaded anywhere.

Your references are stored only in this browser, on this device. Clearing your browser data deletes them, so copy out any collection that matters to you.

How to use the reference manager

When you find a source worth keeping, save it here: the title, the type, the author if you know it, and a note saying what it said and why you are keeping it. A link is optional, and it is shown as plain text only — this page never opens a link for you, and never pretends a saved link is a trusted source. A project name is optional too, and it lets you gather all the references for one piece of work in one place. Each reference saves in this browser only, on this device.

Finding a reference is the whole point of keeping one. Use the search box to find any word in your titles, authors, notes and projects, or use the type filter to see only books, only articles, or only the type you need. The two work together: filter by type, then search within it. The copy button turns the whole collection into plain text, one reference per line, so you can keep a copy anywhere you like.

This page is about keeping your own collection of sources. It is not about writing a reference letter, and it is not a lookup table of keyboard shortcuts or port numbers — those are different pages, with different jobs. Keep the jobs apart, and each page stays simple.

What to save with each reference

Save the title first, because the title is how you will find the reference again. Write it the same way every time — the same spelling, the same short form — or one source will appear twice under two spellings. The type comes next: book, article, website, video or other. The type matters because you use sources differently: a book is a long argument, an article is a single claim, and a website is a page that may change.

Save the author when you know it, because the author tells you how much to trust the source. A claim from an organization that studies the subject is worth more than the same claim from a stranger, and a reference without an author cannot be checked. Save a note too, and make it the most useful part of the reference: what did the source say, in your own words, and why are you keeping it? A reference without a note is a title you will not remember, and a note that says why is worth more than the title itself.

Save the link only if the source lives online, and save it as text you can read, not as a button you press. Links change and pages disappear, which is why the note matters more than the link: the note keeps the idea even when the page is gone. Save the project when the reference belongs to one piece of work, so that the references for that work can be found together.

Types of reference

Books are the slowest references and often the most trustworthy: a book has been written, edited and checked, and it argues a case at length. Save books with their full title and author, and note which chapter or idea you are keeping. A book reference that says only the title is a reminder to re-read the whole book, which is rarely what you need.

Articles are the most common references for research: a single claim, a single study, a single argument. Save the title, the author, and the claim that matters, in your own words. Articles are also the references most likely to be superseded, so note the date when you know it, and check whether newer work has changed the picture before you rely on an old article.

Websites and videos are the least stable references: a page can change overnight, and a video can be taken down without warning. Save them with a note that captures the idea, so that the reference survives even if the page does not. A website reference without a note is a link to a page that may no longer say what it said when you saved it.

Organizing by project

A project is a piece of work — an essay, a report, a talk, a course — and the project field on this page gathers the references that belong to it. Give each project one name, and use that name the same way every time, so that searching for the project finds all of its references. A reference can belong to one project at a time on this page, so if a source serves two projects, save it once and name the project you are working on now.

Organizing by project beats organizing by topic, because a project has a deadline and a purpose, and a topic does not. When you sit down to write, you need the references for this piece of work, not every reference you have ever saved about the subject. The project search gives you exactly that: the sources for the work in front of you, and nothing else.

When a project is finished, its references stay in the collection, and that is a good thing. A finished project's references are a record of what you read and relied on, and they save time when a new project touches the same ground. Delete only the references that proved useless: the rest are the raw material of your future work.

Finding an old reference

The fastest way to find a reference is to search for a word in it. Search looks through titles, authors, notes and projects, so any word you remember will find it. Search for the word you would use to describe the source, and the reference will usually appear at once. If it does not, try the project name, or the author's name, or a word from your note.

The type filter is the second way in. When you need a book rather than an article, filter by type and scan the books. Most collections will have only a handful of references of each type for each project, so scanning takes seconds. The two tools work together: filter by type, then search within it, and even a large collection gives up its references quickly.

Regular review is the third way, and it is the one that keeps a collection honest. Once a month, read through your recent references and ask which ones still matter. The ones that do are worth keeping; the ones that do not can be deleted. A collection that is reviewed stays useful; a collection that is only added to becomes a drawer full of titles.

Citing your sources honestly

A reference collection exists so that you can say where an idea came from. When you use an idea in your own work, name the source: the title, the author, and what the source said. Citing honestly is not a formality, it is the difference between building on someone's work and taking it. Your notes make citing easy, because they already say, in your own words, what each source contributed.

Do not cite a source you have not read. A reference saved from someone else's list, or from a search result you never opened, is a reference you cannot vouch for. Read the source before you cite it, or do not cite it at all. The same rule applies to links: a saved link is not a read source, and a collection full of unread links is a collection of intentions, not of knowledge.

Check the source before you rely on it. Ask who wrote it, when, and why, and whether newer work has changed the picture. A single source is rarely enough for an important claim: look for a second source that agrees, and note the disagreement if the sources conflict. A collection that holds both sides of an argument is more useful than one that holds only the side you agree with.

Common mistakes

The first mistake is saving a title with no note. A reference without a note is a title you will not remember, and a collection of bare titles is a list of books you once meant to read. Always add a note: what the source said, in your own words, and why you are keeping it. The note is the reference; the title is only its name.

The second mistake is trusting a saved link. A link is not a source you have read, and a page can change or disappear after you save it. Read the source, capture the idea in your note, and treat the link as a convenience, not as evidence. The third mistake is never reviewing the collection. A collection that is only added to becomes a drawer full of titles: review it monthly, delete the references that proved useless, and keep the ones that still matter.

The fourth mistake is citing what you have not read. A reference from someone else's list is not your reference until you have read it, and citing it as if you had is dishonest. Read before you cite, or do not cite at all. A small collection of sources you have actually read beats a large collection of titles you have not.
