Claude Artifacts Explained: What They Are and How to Use Them

By the Noryvello team · Published 18 November 2026 · Updated 18 November 2026

An Artifact is a piece of work Claude creates in a separate panel beside the chat, such as a document, a piece of code, a web page, or a diagram. It stays in one place while you talk about it in the chat, so you can read, edit, and download it without losing it in a long conversation. This guide explains what Artifacts are and how to use them.

The problem Artifacts solve is easy to feel. In a plain chat, a long draft gets buried under the conversation. You scroll up to find it, copy it out, paste it back with changes, and the new version gets buried again. An Artifact breaks that cycle by putting the work in its own space. The chat stays on one side for discussion, and the Artifact stays on the other side as the thing you are working on.

Artifacts appear automatically when Claude creates something substantial, such as a document or a piece of code, and you can also ask for one directly. Once an Artifact exists, you can view it, edit it, ask Claude to change it, and download it. The rest of this guide walks through each of those steps in general terms.

Artifact features and controls change between updates, so the steps in this guide are described in general terms rather than as a fixed path. If something looks different on your screen, look for a similarly named option. Always check the content of an Artifact before you use it, since AI-generated text and code can contain errors.

What Artifacts are

An Artifact is a self-contained piece of content that Claude creates and shows in a panel beside the chat. Instead of appearing as one more message in the conversation, it opens as its own thing: a document you can read, a web page you can preview, a diagram you can look at, or a piece of code you can copy. The chat continues alongside it, so you can discuss the Artifact without losing it.

The key idea is separation. The chat is for talking. The Artifact is for the work itself. When you ask Claude to change something, it updates the Artifact in place, so there is always one current version to look at. That is much easier than a chat full of competing drafts, each slightly different from the last.

What appears as an Artifact

Several kinds of content can appear as Artifacts. Documents are the most common: essays, reports, letters, and guides that are long enough to deserve their own space. Code is another: a script, a small program, or a snippet you want to test. Web pages are a third: a simple page built from HTML that you can preview. Diagrams and charts are a fourth: a visual explanation that is easier to read as a picture than as text.

Not everything becomes an Artifact. Short answers, quick explanations, and back-and-forth discussion stay in the chat, where they belong. In general, content becomes an Artifact when it is substantial enough to read, edit, or reuse on its own. If you are unsure whether something will appear as one, just ask Claude to make it an Artifact.

Viewing and working with Artifacts

When an Artifact is created, it usually opens in a panel beside the chat, and you can switch between reading it and talking about it. The panel shows the current version, and each time Claude updates the Artifact, the panel shows the new version. You can usually expand the panel to read a long document comfortably, and collapse it again to focus on the chat.

Working with an Artifact is a loop: read it, talk about it in the chat, ask for a change, and read the new version. Useful requests include "make the introduction shorter", "add a section about costs", and "rewrite the third paragraph in a simpler style." Each request updates the same Artifact, so the work stays in one place instead of spreading across the chat.

Editing an Artifact

You can edit an Artifact in two ways. The first is to edit it directly, changing the text yourself in the panel. This is fastest for small fixes: a typo, a wrong name, a sentence you want to reword. The second is to ask Claude to change it through the chat, which is better for larger changes, such as restructuring a section or rewriting in a different tone.

Most people use a mix of both. Ask Claude to do the heavy work, then fix the details yourself. One habit worth building is to check the whole Artifact after each change, not just the part that changed. An edit in one paragraph can affect the sense of another, and a quick read-through catches problems while they are still easy to fix.

Downloading and sharing

An Artifact lives inside your Claude account, tied to the chat that created it. To use it elsewhere, download it as a file or copy the content out. Downloading is the safer choice, because it puts a copy on your own device that does not depend on the chat still existing. If you delete the chat, the Artifact goes with it, so download anything you want to keep first.

Sharing an Artifact usually means sharing the file you downloaded, or sharing the chat it belongs to. Before sharing, read the content once more and remove anything private. An Artifact can contain details from your conversation that you would not want passed on, such as names, figures, or plans that were only meant for you.

Artifacts vs the chat window

It helps to be clear about what belongs where. The chat window is for conversation: questions, answers, discussion, and short pieces of text. The Artifact panel is for the work product: the document, the code, or the page you are building. Keeping the two separate is what makes Artifacts useful.

A good rule is that anything you would save as a file belongs in an Artifact, and anything you would say out loud belongs in the chat. A draft report is an Artifact. A question about the report is a chat message. A web page is an Artifact. A request to change the colour of a heading is a chat message. When the line is clear, the work flows more smoothly.

When Artifacts help most

Artifacts help most with work that goes through several versions. A document you revise three times, a web page you tweak until it looks right, or a piece of code you test and fix are all good fits. Each round of changes updates the same Artifact, so you always know which version is current. Without an Artifact, those rounds would scatter across the chat and become hard to follow.

They also help when you want to show someone the work without showing them the conversation. An Artifact can be downloaded and sent on its own, while the chat stays private. If your task is a single question with a short answer, you do not need an Artifact at all. But the moment the work becomes a document, a page, or a piece of code, an Artifact makes the whole job easier.

Questions people ask

What kinds of content become Artifacts?

Documents, code, web pages, diagrams, and other self-contained pieces of work can appear as Artifacts. In general, content that you will want to read, edit, or reuse on its own is a good candidate, while short answers stay in the chat.

Can I edit an Artifact directly?

Yes, in general you can edit the text of an Artifact yourself, and you can also ask Claude to change it through the chat. Asking in the chat is better for large changes, while editing directly is faster for small fixes like a typo.

Do Artifacts stay in my chat history?

Yes. An Artifact belongs to the chat that created it, so reopening that chat shows the Artifact again. If you delete the chat, the Artifact goes with it, so download anything you want to keep before deleting.

Can I download an Artifact?

Yes. Artifacts can usually be downloaded as a file, and you can also copy the content out of them. Downloading is the safest way to keep a copy, since it puts the file on your own device.

What if Claude does not make an Artifact?

Ask for one. Say something like turn this into an Artifact, or make this a document I can edit. If the content is short or conversational, it may be better left in the chat, and Claude may say so.
