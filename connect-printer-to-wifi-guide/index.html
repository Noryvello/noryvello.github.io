How to Connect a Printer to Wi-Fi

A printer on your Wi-Fi network can be used by every phone and computer in the house, with no cable needed. Pick a connection method below for the numbered setup steps, and use the troubleshooting checklist if the printer will not connect.

What you need before you start

Before you start, find your Wi-Fi network name and password. The network name is the one your phone connects to at home, and the password is the one you type when a new device joins. If you do not know the password, it is often printed on a sticker on the router. Keep the printer close to the router for the setup, even if you plan to move it later, because a weak signal during setup can cause the connection to fail.

Make sure the printer is switched on and has paper loaded, and check whether it has a screen. Printers with a screen can usually join Wi-Fi on their own. Printers without a screen need another method, such as the WPS button on the router or the maker's app. If you are not sure what your printer supports, the manual will say, and the maker's support pages list the setup options for each model.

Choosing a connection method

The printer's screen is the most straightforward method when the printer has one. You pick your network from a list, type the password, and the printer joins. The WPS button is quicker still: press the button on the router, start WPS on the printer, and the two connect without a password being typed. Not every router has a WPS button, and some routers have it disabled, so check yours first.

The maker's app is the best choice for printers without a screen. The app finds the printer, asks for your Wi-Fi details, and sends them to the printer. A USB cable is the fallback: connect the printer to a computer with the cable, run the setup, and the computer passes the Wi-Fi details to the printer. Once the printer is on the network, you can remove the cable. Whichever method you use, the result is the same: the printer joins your Wi-Fi network and stays connected.

After the printer is connected

Once the printer is on the network, print a test page from the printer's own menu to confirm the connection works. Then add the printer on each phone and computer that will use it. On a phone, open the print option in any app and the printer should appear in the list. On a computer, open the printer settings and add a network printer, and the computer should find it. You only need to add the printer once on each device.

It is worth noting the printer's network name as it appears to your devices, because some homes have more than one printer and the names can look alike. If the printer moves to another room later, check that it still has a good Wi-Fi signal there. A printer in a far corner or behind thick walls may drop off the network, and moving it closer to the router usually fixes that.

Keeping the connection working

A printer that is set up well usually stays connected for a long time, but a few things can break the connection. Changing the Wi-Fi password or the network name will disconnect the printer, and you will need to set it up again with the new details. A new router has the same effect. Moving the printer far from the router can weaken the signal until the printer drops off, so keep it within reasonable range.

If the printer goes offline now and then, check that it is not in a deep sleep mode. Some printers sleep so deeply that they miss print jobs, and waking them with a button press before printing helps. A printer that is switched off at the wall each night will need a minute to reconnect each morning. Leaving it on, or in its normal sleep mode, avoids that wait.

Questions people ask

What is WPS and should I use it to connect my printer?

WPS is a button on many routers that lets a printer join the Wi-Fi network without typing the password. Press the WPS button on the router, then start WPS on the printer within a couple of minutes. It is the quickest method when both devices support it.

Why can my phone see the printer but my computer cannot?

The phone and the computer are probably on different networks. Check that both are on the same Wi-Fi network name, and that neither is on a guest network. Restarting the printer and the computer also helps.

Do I need the printer maker's app to set up Wi-Fi?

Not always. Printers with a screen can usually join Wi-Fi from the screen alone. Printers without a screen often need the maker's app or a temporary USB cable connection for the first setup.

What if my printer has no screen?

Use WPS if your router has the button, or use the maker's app, which walks you through the setup on your phone. Some models can also be set up over a USB cable from a computer.

Will the printer stay connected if I change my Wi-Fi password?

No. If you change the Wi-Fi password or the network name, the printer will lose its connection and you will need to set it up again with the new details.
