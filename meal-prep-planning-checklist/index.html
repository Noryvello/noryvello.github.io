How the four phases work

The checklist is split into four phases so the work is spread out instead of landing all at once. Planning comes first: pick the meals, check what you already have, and write a list. Then shop, then prep — washing, chopping and cooking in one session — and finally store everything in labelled containers.

How many containers do you need?

Allow one container per serving. If you are cooking 8 servings, you need 8 containers, because each serving gets its own container. A part-serving still needs a container of its own, so the helper rounds up. The batch-cook helper above does the sum and shows the working.

Storing your meals

Let cooked food cool before you put the lids on, and use clean containers with lids that close properly. Label each container with what is inside so you can find meals quickly, and keep the containers cold in the fridge. Use the oldest meals first, and if food looks or smells off, throw it out.

Questions people ask

How do I start meal prepping?

Start small: pick two or three meals for the week, write a shopping list, and set aside one session to cook and portion them. The checklist on this page walks through the four phases — plan, shop, prep day and store — so you can tick each step off as you go.

How many containers do I need for meal prep?

Plan on one container per serving. If you are cooking 8 servings, you need 8 containers, because each serving gets its own container. The batch-cook helper above does the sum for you.

How should I store meal prep food?

Let cooked food cool before you put the lids on, use clean containers with lids that close properly, and label each container with what is inside. Keep the containers cold in the fridge, and use the oldest meals first.

How far ahead can I prep meals?

Most people prep for the meals ahead in the coming week, starting with the next few days. Keep it simple at first: prep a small batch, see how it goes, and build up from there. If food looks or smells off, throw it out.
