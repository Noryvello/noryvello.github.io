How to pick a dataset

Start with the question, not the data. Write down in one sentence what you want to find out — for example, how rainfall in one country has changed over ten years — and only then look for a dataset that answers it. Check five things before you download anything. First, the topic: does the source actually cover your subject? Second, the years: does it cover the period you need, and how recent is the latest year? Third, the licence: most public datasets are free to use with credit, but a few limit commercial use, so read the licence line. Fourth, the format: CSV and Excel open in a spreadsheet, JSON and APIs suit programmers, and PDF tables are the hardest to work with. Fifth, the size: a file of a few megabytes is easy to handle, while a file of several gigabytes needs a plan. If a dataset fails the first two checks, keep looking — the wrong data is worse than no data.

The licence deserves a closer look, because it is the part people skip. Most public datasets use an open licence, which means you may use, share and build on the data as long as you credit the source. Some licences add conditions: no commercial use, or share your own work under the same licence. A few datasets are free to look at but not free to republish. The licence is usually one line on the source's download page, and reading it takes a minute. If you plan to publish your project — on a website, in a report or in a video — that minute protects you from a request to take the work down later.

How to use a dataset for a school or work project

A dataset becomes a project in five steps. First, state the question in one sentence. Second, pick the source from the table above and read its description page, which usually explains what each column means. Third, download the file and open it to check it looks right — the right country, the right years, no empty columns. Fourth, answer the question with a small table or chart, and write down what the data does and does not show. Fifth, credit the source: name it, give its address, and note the date you downloaded the data. That last step matters as much as the first — a project without a source cannot be checked, and a teacher or a colleague will ask where the numbers came from.

Finding one dataset, step by step

Suppose a student needs climate data for a school project on rainfall. She types climate in the search box above and sees several sources. She picks NOAA NCEI, the weather and climate records source, because it covers her country and her years. On the source's own site she reads the description, downloads a CSV file of monthly rainfall, and opens it in a spreadsheet. She checks the years run from 2010 to 2024, notes the source name and the download date, and then makes a simple chart of rainfall by year. Her project states the question, shows the chart, names the source, and says plainly that the data covers one weather station, not the whole country. That honesty is what makes the work trustworthy.

Common mistakes

The most common mistake is the wrong licence: using data in a published project without checking whether the licence allows it. The second is old data: a dataset from 2015 does not answer a question about today, so always check the latest year. The third is no source cited — numbers without a source are just claims. The fourth is a file too big to handle: download a sample first, or pick the smaller format, before you commit to a huge download. The fifth is mixing units: one source measures rainfall in millimetres and another in inches, and a chart that mixes them is wrong. Check the units column before you combine anything.

A sixth mistake is trusting the first file you find. Search results favour popular datasets, not suitable ones, and a famous dataset about the wrong country or the wrong years is still the wrong dataset. Open the description page, read what the columns mean, and check the coverage before you download. A related mistake is never looking at the raw file: a quick scroll through the first rows shows missing values, strange codes and empty columns that a chart would hide. Ten minutes of looking saves hours of fixing later.

What this directory cannot do

This directory points to sources; it does not host data, check every file, or promise that a link will never change. Official sites do move pages, and a source can change its licence or its format. If a link fails, search for the source by name — official sources are easy to find. The page also cannot pick the right dataset for you: only your question can do that, which is why the checklist above starts with the question and not the download.

Questions people ask

What is a public dataset?

A public dataset is a collection of data that anyone may use, usually published by a government, an international organisation or a research group. It might be a table of numbers, a list of places, or a set of measurements. Most are free to download and use, often with a licence that asks you to credit the source.

Are these datasets really free?

Almost all of the sources in this directory are free to use. A few, such as Statista, mix free material with paid material — the table says so where that is the case. Always read the licence line on the source's own site before you publish anything made from the data.

Can I use them in my school project?

Yes. Public datasets are made for exactly that: school projects, homework, university work and personal research. Credit the source by name, give its address, and note the date you downloaded the data, so a teacher can check your work.

What format will the data be in?

Most often CSV or Excel, which open in a spreadsheet. Some sources offer JSON or an API for programmers, and some offer PDF tables, which are the hardest to work with. The Format column in the table tells you what each source offers before you visit it.

How do I know if data is trustworthy?

Check three things: who published it, how recent it is, and whether it says how the data was collected. Official sources — governments, the UN, the World Bank — publish their methods, and that is what makes them trustworthy. Be careful with data that has no publisher, no date and no method.

Do I need to credit the source?

Yes, in almost every case. The licence usually asks for credit: name the source, give its address, and note the date you downloaded the data. Crediting the source is not only polite — it lets anyone check your work, which is what makes it trustworthy.
