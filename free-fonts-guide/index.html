Free Fonts Guide

Good free fonts are easy to find, but a font that costs nothing can still carry licence rules. This guide points you to legitimate sources, explains the licences you will meet, and shows you how to pair fonts so headings and body text work well together.

Fonts shape how words feel before they are even read. The same sentence set in a plain sans-serif and in a handwritten script says two different things, and choosing fonts well is one of the cheapest ways to make a page, a poster or a presentation look cared for.

This guide covers legitimate sources only. It names the libraries worth using, explains font licences in plain words, and gives you a licence checker and a pairing picker to help you choose.

Legitimate sources

The best-known source of free fonts is Google Fonts, a library of open-licensed fonts that can be used in print and on the web, with the licence stated on every font page. Font Squirrel is another well-regarded library that lists only fonts cleared for commercial use, and it says so plainly on each font page. The League of Moveable Type publishes a small collection of open-licensed fonts, and many independent designers release their work under the SIL Open Font License.

Whatever the source, the licence is what matters, not the download button. A legitimate font page states the licence clearly, names the designer, and lets you download the font file directly. A page that hides the licence, or that bundles the font with other downloads, is not a page to trust.

Be careful with font aggregator sites that collect fonts from anywhere and republish them. Some of these sites list commercial fonts as free, and downloading from them can leave you using a font you have no right to use. When in doubt, go back to the designer's own page or to one of the libraries named above.

Font licences explained

The SIL Open Font License, usually shortened to OFL, is the most common licence for free fonts. It allows you to use the font freely, including in commercial work, and to share it with others. You may not sell the font file itself, and if you change the font, the changed version must use a different name. Most fonts in Google Fonts use this licence.

Free for commercial use is a plain statement rather than a formal licence name: it means you may use the font in work you sell or publish. Read the full licence on the font page, because some fonts that are free for commercial use still limit redistribution of the font file itself.

Free for personal use only is the licence to watch out for. It means you may use the font for your own projects that you do not sell or publish commercially. A personal-use-only font must not be used in a logo, a client project or anything you sell. If you like a personal-use font and want it for commercial work, look for the designer's commercial licence.

Trial and demo fonts are samples, not licences. They often miss characters or weights, and they are meant for trying a font in drafts. Replace a trial font with a properly licensed font before anything goes public. Use the licence checker above to test any licence before you use a font.

Pairing fonts

Most projects need two fonts: one for headings and one for body text. The pair should contrast enough to tell the reader what is a heading and what is text, but not so much that the page feels like two different documents. The safest pairings contrast in one way only: a serif heading with a sans-serif body, or two weights of the same family.

Serif headings with a plain sans-serif body give a classic, readable feel, and suit long documents. Sans-serif headings with serif body text feel modern and calm. Handwritten fonts work for headings only — they are hard to read in long text — and they need the plainest possible body font beside them. Monospace headings suit technical and playful pages, and also pair best with a plain sans-serif body.

Two fonts is enough for most projects, and three is the most any page should carry. Each extra font adds noise, and a page with four or five fonts looks unsettled even when the reader cannot say why. If you want variety, use weights and sizes of the same two fonts instead of adding a third.

Test a pairing at the size you will actually use, with real text rather than placeholder words. A pairing that looks good in a specimen can fail in a long paragraph, and the only way to know is to set a page of your own words in it and read it.

Installing and managing fonts

Installing a font is usually a matter of opening the font file and choosing install, on a computer or a phone. The font then appears in your apps. Before you install, check the file: a font file should be a single file in a standard font format, and it should come from the source you chose, not from a bundle.

Keep your font collection small. Every installed font adds to the list you scroll through in every app, and a long list slows you down more than it helps. Install the fonts you are using for current projects, and remove the rest. You can always download a font again from its source if you need it later.

When you share a document, remember that the reader may not have your fonts. If the document must look the same everywhere, export it as a PDF or an image, which keeps the letterforms fixed, rather than sharing the editable file and hoping the reader has the same fonts installed.

Never download a font from a site you do not trust, and never install a font file you cannot trace to its licence. A font with no licence is not a free font, and using it in a published project can cause trouble later.

Questions people ask

Are free fonts safe to download?

From legitimate libraries such as Google Fonts and Font Squirrel, yes. Avoid aggregator sites that republish fonts without clear licences, and never download a font bundled with other software.

What does the SIL Open Font License allow?

It allows you to use the font freely, including in commercial work, and to share it with others. You may not sell the font file itself, and a changed version must use a different name.

Can I use free fonts in a logo?

Yes, if the licence allows commercial use, as the SIL Open Font License does. Never use a personal-use-only font in a logo or anything you sell.

How many fonts should I use in one project?

Two is enough for most projects: one for headings and one for body text. Three is the most any page should carry, and extra variety should come from weights and sizes, not more fonts.

What is a good font pairing?

A pair that contrasts in one way only, such as serif headings with a sans-serif body, or two weights of the same family. Use the pairing picker above for guidance by heading style.
