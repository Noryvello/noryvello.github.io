YouTube Thumbnail Downloader

Get the thumbnail image of any YouTube video in four sizes. Paste a video link or ID and this tool finds the thumbnail images, checks which sizes exist, and lets you open each one to save it.

Thumbnails belong to the video owner. Only use a thumbnail where you have the right to do so, and note that this tool does not download the video itself.

Which size should you use

Four sizes are available for most videos. The default size is small and suits tiny previews. The medium size works for lists and small cards. The high-quality size suits most everyday uses, such as a blog post or a slide. The maximum-resolution size is the sharpest and suits large displays and printed material.

Pick the smallest size that still looks sharp where you will use it. A small image stretched large looks blurry, while a very large image used tiny only wastes space.

Why a size may be missing

The maximum-resolution thumbnail only exists when the video was uploaded in high resolution, so older videos and videos uploaded at low quality often have no maximum-resolution image. When a size does not exist, the tool says so plainly instead of showing a broken image.

Every size is checked in your browser when you fetch the thumbnails, so the result reflects what is actually available for that video right now.

Saving a thumbnail

Each size has its own Open image button, which opens the picture in a new tab. From there, save it the way you save any image in your browser: right-click or long-press and choose the save option. The Copy link button copies the direct image address, which you can paste into a document or share with someone else.

The image files come straight from the video platform, so what you save is the original thumbnail at that size, with no recompression or watermark added by this tool.

Questions people ask

What links work here?

Watch links, short youtu.be links, embed links and Shorts links all work, and so does the 11-character video ID on its own. Paste the link exactly as it appears in your browser address bar.

Why do images open in a new tab?

Thumbnail images come from another site, and browsers do not allow one site to force-download an image from another. Opening the image in a new tab lets you save it with your browser instead.

Does this need an API key?

No. Thumbnails are public image files with predictable addresses, so the tool builds the address for each size and checks it directly in your browser.

Can I download the video?

No. This tool only finds the thumbnail image. It cannot download video or audio from YouTube.
