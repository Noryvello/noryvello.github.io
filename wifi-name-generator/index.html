Choosing a useful network name

  • Choose something guests can identify without revealing who lives there.
  • Avoid confusing characters if people will need to type the name.
  • Do not use the WiFi name as a password.
  • Use your router's settings to change the network name; this page only creates ideas.
A note before you act: Avoid names that reveal personal details or your address. A network name can be visible to nearby people, so keep identifying information out of it.

Frequently asked questions

Can a WiFi name contain spaces?

Many routers allow spaces in a network name, but supported characters and length limits can vary. Check your router's settings if a name is rejected.

Should I put my name or apartment number in my WiFi name?

It is safer not to. Nearby people may be able to see the network name, so avoid personal details and location clues.

Does changing my WiFi name change my password?

Usually the network name and password are separate settings. Changing the name does not necessarily change the password, so review both in your router settings.

Can I use these generated names for a business network?

You can use them as inspiration, but choose a clear, professional name that does not expose private information or confuse visitors.
