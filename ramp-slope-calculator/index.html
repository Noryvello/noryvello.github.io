How the maths works

A ramp slope can be described three ways, and all three come from the same two numbers: the rise (how high the ramp climbs) and the run (the flat horizontal distance it covers).

  • Slope ratio: run ÷ rise, written as 1:X. A ratio of 1:12 means the ramp rises 1 unit for every 12 units of run.
  • Slope percentage: rise ÷ run × 100. A 1:12 slope is about 8.33%.
  • Slope angle: arctan(rise ÷ run), in degrees. A 1:12 slope is about 4.76 degrees.

If you measured the slope length instead of the run — the distance along the ramp surface itself — the run is worked out first with Pythagoras: run = √(slope length² − rise²). That is why the slope length must be longer than the rise: a ramp's sloping surface is always longer than the height it climbs.

Worked examples

Example 1 — rise 0.5, run 6. Ratio: 6 ÷ 0.5 = 12, so 1:12. Percentage: 0.5 ÷ 6 × 100 = 8.33%. Angle: arctan(0.5 ÷ 6) = 4.76°.

Example 2 — rise 1, slope length 5. Run = √(5² − 1²) = √24 = 4.90. Ratio: run ÷ rise = 4.90, so 1:4.90. Percentage: rise ÷ run × 100 = 20.41%. Angle: arctan(rise ÷ run) = 11.54°. The percentage and angle use the full run value (4.898979…), not the rounded 4.90.

Example 3 — rise 0.3, run 3. Ratio: 3 ÷ 0.3 = 10, so 1:10. Percentage: 0.3 ÷ 3 × 100 = 10.00%. Angle: arctan(0.3 ÷ 3) = 5.71°.

Gentle or steep?

A gentle slope is often given as 1:12, which is about 4.8 degrees. Steeper slopes are harder to use — pushing a wheelchair or a heavy load up a steep ramp takes much more effort, and a very steep ramp can be unsafe. The gentler the slope, the longer the ramp needs to be for the same rise: a 1:12 ramp needs 12 units of run for every 1 unit of rise.

Remember that 1:12 is common general guidance, not a building rule. Local rules and standards may differ, and they may set a different slope for ramps in public buildings, so always check the rules that apply where the ramp will be built.

Questions people ask

What does a slope ratio of 1:12 mean?

It means the ramp rises 1 unit for every 12 units of horizontal run. A ramp that rises 0.5 over a run of 6 has a ratio of 1:12, because 6 divided by 0.5 is 12.

What is a gentle slope?

A gentle slope is often given as 1:12, which is about 4.8 degrees. Steeper slopes are harder to use, especially for wheelchairs and heavy loads. This is general guidance, not a building rule, and local rules may differ.

Should I enter the run or the slope length?

Enter whichever you measured. The run is the flat horizontal distance, while the slope length is the distance along the ramp surface itself. Pick the matching option above and the calculator works out the run for you.

Is 1:12 a building rule?

No. The 1:12 figure is common general guidance for a gentle slope, not a building rule. Local rules and standards may differ, so check the rules that apply where the ramp will be built.
